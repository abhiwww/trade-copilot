# Trade Copilot User Guide
# ==================================

Welcome to Trade Copilot, your AI-powered trade intelligence partner.

## Quick Start
1. **Create a Case**: Start by creating a Trade Case. Define your origin, destination, and product.
2. **Upload Documents**: Attach your commercial invoices, packing lists, or LCs. The AI will automatically index them.
3. **Ask Questions**: Use the chat to ask about compliance, find discrepancies, or summarize document contents.

## Key Features
- **Document Intelligence**: Real-time extraction of trade fields.
- **Compliance Checks**: Automatic flagging of missing certificates or regulatory risks.
- **Risk Scoring**: Get an overall risk level for your shipment.

## Troubleshooting
- If a document fails to process, check the file format (PDF/TXT preferred).
- Ensure your organization plan allows more uploads if you hit a quota limit.
